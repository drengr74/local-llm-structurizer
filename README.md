# Структурирование данных через Ollama

Локальное приложение читает текст построчно, отправляет его в модель `llama3.2` и сохраняет результат в `output.json`. Схему можно выбрать вручную или определить автоматически.

Нужны Python 3.10+ и установленное приложение [Ollama](https://ollama.com) с загруженной моделью.

## Установка

```bash
pip install -r requirements.txt
ollama pull llama3.2
```

## Запуск

Интерфейс в браузере:

```bash
python app.py
```

Откроется `http://127.0.0.1:8765`. В окне выбирается схема, вставляется текст (одна запись на строку) и запускается разбор. Карточки появляются по мере готовности, итог записывается в `output.json`. Остановка сервера: Ctrl+C.

Тот же разбор в терминале, из `input.txt`:

```bash
python app.py --cli
python app.py --cli --schema person
python app.py --cli --schema product
```

Без `--schema` и со значением `auto` схема определяется для каждой строки. Явный `--schema person` или `--schema product` отключает автоопределение.

## Файлы

| Файл | Назначение |
| --- | --- |
| `app.py` | Обработка строк, интерфейс и режим `--cli` |
| `web/index.html` | Страница интерфейса |
| `schemas.json` | Схемы `person` и `product` |
| `input.txt` | Текстовые строки для режима `--cli` и кнопка «Вернуть input.txt» |
| `output.json` | Список результатов последней обработки |

В каждой записи есть `detected_schema` (`auto` или `manual`), имя схемы и поля `data`. Если строка не подошла ни к одной схеме, в записи будет `unknown` и сообщение «данные не распознаны». Ошибка одной строки не останавливает остальные.
